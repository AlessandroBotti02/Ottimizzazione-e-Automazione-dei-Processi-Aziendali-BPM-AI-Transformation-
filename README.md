🎯 Obiettivo del progetto
Ottimizzare i processi aziendali (BPM) del cliente per:

capire come funzionano oggi (AS-IS)
individuare inefficienze e rischi (compliance, dati, operatività)
ridisegnarli (TO-BE)
valutare dove introdurre AI e automazioni
🧱 Fasi del progetto
1. Impostazione iniziale
Raccolta info base cliente
Costruzione mappa processi L1–L3
Identificazione:
attori coinvolti (RACI alto livello)
perimetro (es. AFC iniziale)
Validazione con cliente
👉 Fondamentale: partire da una mappa condivisa prima di intervistare

2. Analisi compliance
Raccolta normative applicabili (GDPR, sanità, sicurezza, ecc.)
Creazione matrice:
processo ↔ normativa
criticità (alta/media/bassa)
Verifica con cliente (“siete davvero soggetti a queste?”)
3. Interviste di processo
Interviste strutturate per ogni processo (livello L3)
Raccolta:
attività (step-by-step)
sistemi usati
dati gestiti
interazioni tra ruoli
inefficienze/pain point
👉 Approccio:

1 attore alla volta
poi integrazione tra interviste
4. Modellazione AS-IS (ESIS)
Trasformazione interviste in:
flow BPMN (processi)
mappa completa end-to-end
Uso tool (CoWork / Copilot)
Validazione con cliente
5. Analisi quantitativa (FTE)
Per ogni attività:
tempo
frequenza
driver (es. fatture)
Attenzione a:
picchi (attività concentrate)
Output:
dimensionamento risorse
effort totale
6. Analisi dati
Identificazione:
master data
dati transazionali
Collegamento:
dati ↔ attività ↔ sistemi
Costruzione modello dati base
7. AI Readiness & automazione
Valutazione processi su 3 livelli:

Non automatizzabili (dipendono da competenze)
Supportabili (AI come assistente)
Automatizzabili (agenti / workflow)
Identificazione use case AI
Costruzione logica agenti (Copilot / CoWork)
8. Redesign TO-BE
Riprogettazione processi usando logiche BPR:
parallelizzazione attività
riduzione passaggi
spostamento decisioni
Inserimento AI dove ha senso
9. Metriche & valutazione
Definizione KPI:

tempo ciclo
FTE
compliance
AI readiness
valore aggiunto vs non valore
10. Output finale
Mappa processi AS-IS
Mappa TO-BE
Matrice compliance
Analisi FTE
Modello dati
Roadmap AI / automazione
🧠 Logica generale del progetto
Capisco → (interviste + mappa)
Misuro → (FTE + dati)
Valuto → (compliance + AI readiness)
Miglioro → (TO-BE)
